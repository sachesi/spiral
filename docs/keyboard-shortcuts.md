# Keyboard shortcuts

Ctrl+? shows this list inside the application.

| Keys | |
|---|---|
| Ctrl+N | New window |
| Ctrl+T | New tab |
| Ctrl+W | Close tab |
| Ctrl+Shift+W | Close window |
| Ctrl+Shift+O | Tab overview |
| Ctrl+, | Preferences |
| Ctrl+Q | Quit |
| Ctrl+Z, Ctrl+Shift+Z | Undo, redo |
| Alt+Left, Alt+Right | Back, forward |
| Alt+Up, Backspace | Parent folder |
| Alt+Home | Home |
| Ctrl+L | Type a location |
| Ctrl+F | Search the folder |
| F5, Ctrl+R | Reload |
| Ctrl+D | Bookmark the folder |
| Ctrl+1, Ctrl+2 | Grid or list |
| Ctrl++, Ctrl+- | Zoom |
| Ctrl+H | Hidden files |
| F9 | Sidebar |
| Ctrl+A | Select all |
| Ctrl+X, Ctrl+C, Ctrl+V | Cut, copy, paste |
| F2 | Rename |
| Ctrl+Shift+N | New folder |
| Delete | Move to trash |
| Shift+Delete | Delete permanently |
| Alt+Return | Properties |
| Menu, Shift+F10 | Context menu |

Tab switching (Ctrl+Page Up/Down, Alt+1 to 9) is libadwaita's. In the location entry,
Tab accepts the completion and Esc cancels. Typing with the view focused starts a search.
